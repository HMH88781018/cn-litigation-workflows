# Synthetic examples

Every public example is synthetic. It demonstrates data contracts and failure
handling, not a real filing or legal conclusion.

- `synthetic-evidence-manifest.json` shows the separation between evidence
  order, page ranges, facts and claims.
- `synthetic-damages-input.json` shows sourced parameters, gaps and manual
  decisions without using a person's identity or current local statistics.

Do not replace placeholders with real matter data in the repository. Copy an
example to a private, authorized workspace first.
