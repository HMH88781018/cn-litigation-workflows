# Privacy Policy

Effective date: 2026-07-29

CN Litigation Workflows is a local, open-source plugin bundle. It has no hosted
service, account system, telemetry, analytics, advertising or bundled MCP
server. The project itself does not transmit, retain or sell user data.

## Data processed

When a user invokes a Skill, ChatGPT, Codex, the operating system and any tools
the user separately chooses may process the files and text supplied to them.
Those products and tools are governed by their own terms and privacy settings.
This repository does not receive that content.

## Sensitive legal information

Legal matters can contain identity data, health information, financial data,
communications, evidence and legally privileged or confidential material.
Users must:

1. use an environment authorized for the matter;
2. minimize and redact data before testing or sharing;
3. never place real matter data in public issues, pull requests, CI logs or
   example files;
4. review generated logs and reports before distribution;
5. follow applicable professional, contractual and legal duties.

The DOCX audit tool omits full document text by default and produces structural
fingerprints. Full text is included only when a user explicitly selects the
`--include-text` option.

## Third parties and retention

This project sends no data to third parties and defines no retention period
because it operates locally and stores nothing centrally. Local outputs remain
where the user or host product saves them. Users control deletion and
retention in those locations.

## Contact

Open a privacy issue containing no confidential or personal information, or
use GitHub's private security-reporting channel when disclosure itself is
sensitive.
